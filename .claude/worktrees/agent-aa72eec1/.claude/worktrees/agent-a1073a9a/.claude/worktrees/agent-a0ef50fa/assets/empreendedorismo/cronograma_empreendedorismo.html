Aula 01 — Conceitos, perfil e criatividade
HOJE
▼
ConceitosEstudar a definição científica de empreendedorismo: criar algo novo com valor, assumindo riscos financeiros, psíquicos e sociais — vai além de abrir um CNPJ
5CsMemorizar os 5Cs da gestão profissional: Coração (propósito), Cliente (produto nasce da dor), Caixa (lucro), Cadência (disciplina), Cultura (personalidade do negócio)
PerfilRevisar o perfil empreendedor: mentalidade de treino (fazer + errar + aprender) e mentalidade do fundador ("cabeça de dono", missão insurgente)
Lean StartupCiclo Construir-Medir-Aprender: o que é MVP (menor esforço para validar uma hipótese) — exemplo do Dropbox (vídeo antes do produto)

07/04 Ter
Aula 03 completa — O conteúdo mais cobrado
FOCO
▼
PersonaPersona vs público-alvo: público-alvo é genérico ("jovens 18–25"), persona é específica (hábitos, dores, objetivos). "Quem tenta falar com todo mundo, não conecta com ninguém."
Escuta ativaO que é escuta ativa: ouvir com atenção genuinamente, sem confirmar hipóteses. Sem ela: sistema baseado em "achismos", interface ruim, alta taxa de abandono
ValorOrientação ao cliente: o valor não está no código, mas na percepção do usuário sobre o quanto o produto resolve seu problema
Proposta de ValorAs 3 perguntas fundamentais: 1) Qual problema você resolve? 2) Como você resolve? 3) Qual benefício real o cliente obtém? Se o usuário não entende rapidamente, ele não usa.
Frases-chaveGravar: "Quem escuta melhor, erra menos" e "Código constrói sistemas. Mentalidade constrói negócios."
